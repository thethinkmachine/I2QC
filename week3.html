The Historical Landscape of Quantum Algorithms

Quantum computing did not emerge with a fully-formed toolbox of algorithms. The field developed gradually, with each major algorithm building conceptually on the last. Understanding this timeline gives context for why each algorithm was important.

1985
Deutsch's Algorithm
David Deutsch proves a simple problem (constant vs balanced on 1 bit) can be solved with 1 quantum query vs 2 classical. First quantum speedup.
1992
Deutsch-Jozsa (DJ)
Generalization to n bits: 1 quantum query vs exponentially many classical queries. First exponential separation, though the problem is somewhat artificial.
1992
Bernstein-Vazirani (BV)
Find a hidden n-bit string: 1 quantum query vs n classical. More natural problem than DJ. Introduces "recursive Fourier sampling."
1993
Simon's Algorithm
Exponential speedup for finding hidden XOR structure. Directly inspired Shor's algorithm.
1994
Shor's Algorithm
Polynomial-time quantum factoring. Breaks RSA. The most famous quantum algorithm.
1996
Grover's Search
Quadratic speedup for unstructured search: O(√N) vs O(N). Provably optimal. Broadly applicable.
2014+
NISQ-era: VQE, QAOA, QML
Variational algorithms designed for near-term noisy hardware. Week 4 topic.

The Query Complexity Model

All three algorithms this week operate in the query complexity model. This model is abstract and clean — it lets us prove quantum speedups rigorously without worrying about circuit implementation details.

📐 Query Complexity Model

We are given a function $f: \{0,1\}^n \to \{0,1\}$ as a black-box (oracle). We are not allowed to inspect the implementation of $f$ — we can only evaluate it on inputs. The cost of the algorithm is measured in the number of queries (function evaluations) made.

The question: how many queries does it take to determine some property of $f$? We compare the classical and quantum query complexities.

Oracles: The Quantum Black-Box

A classical function $f: \{0,1\}^n \to \{0,1\}$ is not directly usable in a quantum circuit (classical computation is irreversible; quantum gates must be unitary). We encode $f$ as a quantum gate called an oracle.

📐 Standard Quantum Oracle $U_f$

The oracle $U_f$ acts on two registers — an $n$-qubit input register $|x\rangle$ and a 1-qubit target register $|y\rangle$:

$$U_f: |x\rangle|y\rangle \mapsto |x\rangle|y \oplus f(x)\rangle$$

where $\oplus$ denotes XOR (addition modulo 2). This is unitary because applying $U_f$ twice gives $|x\rangle|y \oplus f(x) \oplus f(x)\rangle = |x\rangle|y\rangle$, i.e., $U_f^2 = I$.

Crucially, when $x$ is in superposition, $U_f$ computes $f(x)$ on all inputs simultaneously:

$$U_f \cdot \frac{1}{\sqrt{2^n}}\sum_x |x\rangle|0\rangle = \frac{1}{\sqrt{2^n}}\sum_x |x\rangle|f(x)\rangle$$
⚡ Phase Oracle (Used in Grover)

When the target register is in state $|{-}\rangle = \frac{|0\rangle - |1\rangle}{\sqrt{2}}$, something magical happens:

$$U_f|x\rangle|{-}\rangle = |x\rangle\frac{|f(x)\oplus 0\rangle - |f(x)\oplus 1\rangle}{\sqrt{2}} = (-1)^{f(x)}|x\rangle|{-}\rangle$$

The function value "kicks back" into the phase of the input state! So for the marked element (where $f(x)=1$), the phase becomes $-1$. This is the phase kickback trick — one of the most important techniques in quantum computing.

The Deutsch-Jozsa Algorithm

The Deutsch-Jozsa algorithm solves a problem that seems tailor-made for quantum computers — because it was. David Deutsch invented it to prove, in principle, that quantum computers can do something no classical computer can match with the same number of queries.

📐 The Deutsch-Jozsa Problem

Input: A black-box function $f: \{0,1\}^n \to \{0,1\}$ promised to be either:

  • Constant: $f(x) = 0$ for all $x$, or $f(x) = 1$ for all $x$
  • Balanced: $f(x) = 0$ for exactly half the inputs, and $f(x) = 1$ for the other half

Task: Determine whether $f$ is constant or balanced.

Classical Lower Bound

Consider the classical deterministic algorithm for this problem. In the worst case, how many queries do we need to be certain of the answer?

Suppose $f$ is constant with value 0. If we query $f$ on the first $2^{n-1}$ inputs and they all return 0, we still can't be sure: perhaps $f$ is balanced and all the 1's happen to be in the half we haven't queried yet! We need $2^{n-1} + 1$ queries to be certain: if after querying $2^{n-1}+1$ inputs we've seen both 0 and 1, it's balanced; if all the same, it must be constant.

$$\text{Classical deterministic query complexity} = 2^{n-1} + 1 \quad \text{(exponential in } n)$$ $$\text{Quantum query complexity} = 1 \quad \text{(always)}$$
🔍 Probabilistic Shortcuts

A randomized classical algorithm can distinguish constant from balanced with high probability in just a few queries ($O(1)$ expected). So the exponential separation only holds between exact deterministic classical (EQP class) and exact quantum algorithms. The DJ algorithm is still a landmark because it gives the first provable exponential gap between quantum and exact classical computation.

The Quantum Circuit

n-qubit Deutsch-Jozsa Circuit: |0⟩ᵢ⊗ⁿ ─ H⊗ⁿ ─────── U_f ─── H⊗ⁿ ─── [M⊗ⁿ] ─── output │ |1⟩ ──── H ─── ┘ (target ancilla qubit, not measured) Measure output register. If all 0s: f is constant. Otherwise: balanced.

Full Circuit Derivation

Let us trace through this carefully. We have $n+1$ qubits: $n$ query qubits and 1 ancilla (target) qubit.

1
Initialize: Query register in $|0\rangle^{\otimes n}$, ancilla in $|1\rangle$: $$|\psi_0\rangle = |0\rangle^{\otimes n}|1\rangle$$
2
Apply $H^{\otimes n}$ to query register, and $H$ to ancilla: $$|\psi_1\rangle = \left(\frac{1}{\sqrt{2^n}}\sum_{x\in\{0,1\}^n}|x\rangle\right)\left(\frac{|0\rangle-|1\rangle}{\sqrt{2}}\right) = \frac{1}{\sqrt{2^n}}\sum_x|x\rangle|{-}\rangle$$ The query register is now in uniform superposition over all $2^n$ inputs!
3
Apply oracle $U_f$ (phase kickback): Since the ancilla is $|{-}\rangle$, the phase kickback gives $(-1)^{f(x)}$ for each $|x\rangle$: $$|\psi_2\rangle = \frac{1}{\sqrt{2^n}}\sum_x (-1)^{f(x)}|x\rangle|{-}\rangle$$ The information about $f$ is now encoded in the phases of the superposition.
4
Apply $H^{\otimes n}$ to the query register: The Hadamard transform converts phase information back into amplitude information. Using the identity $H^{\otimes n}|x\rangle = \frac{1}{\sqrt{2^n}}\sum_z (-1)^{x\cdot z}|z\rangle$ (where $x\cdot z = \bigoplus_i x_i z_i$ is the bitwise dot product mod 2): $$|\psi_3\rangle = \frac{1}{2^n}\sum_x\sum_z(-1)^{f(x)}(-1)^{x\cdot z}|z\rangle = \sum_z\left(\frac{1}{2^n}\sum_x(-1)^{f(x)+x\cdot z}\right)|z\rangle$$ The amplitude of $|z\rangle$ is: $A_z = \frac{1}{2^n}\sum_x(-1)^{f(x)+x\cdot z}$
5
Measure the query register:
  • If $f$ is constant ($f(x) = c$ for all $x$): $A_z = \frac{(-1)^c}{2^n}\sum_x(-1)^{x\cdot z}$. For $z = 0^n$ (all zeros): $A_0 = (-1)^c \neq 0$. For $z \neq 0^n$: $\sum_x (-1)^{x\cdot z} = 0$ (balanced sum). So we measure $|0\rangle^{\otimes n}$ with probability 1!
  • If $f$ is balanced: For $z = 0^n$: $A_0 = \frac{1}{2^n}\sum_x(-1)^{f(x)} = 0$ (half +1, half -1, sum is 0). So we never measure $|0\rangle^{\otimes n}$.

Conclusion: If measurement gives all zeros: constant. If any non-zero: balanced. Always correct, using exactly 1 oracle query.

The Bernstein-Vazirani Algorithm

The Bernstein-Vazirani (BV) algorithm solves a more natural and interesting problem than Deutsch-Jozsa. It has a similar circuit but achieves a different type of speedup (linear $n$ vs $1$, rather than exponential).

📐 The Bernstein-Vazirani Problem

Input: A black-box function $f_s: \{0,1\}^n \to \{0,1\}$ defined as:

$$f_s(x) = s \cdot x \pmod{2} = s_1 x_1 \oplus s_2 x_2 \oplus \cdots \oplus s_n x_n$$

where $s \in \{0,1\}^n$ is an unknown hidden secret string.

Task: Determine the secret string $s$ exactly.

Classical Lower Bound

To determine $s$ classically, we can query $f$ on the standard basis vectors:

$$f(e_i) = s \cdot e_i = s_i$$

Each query reveals one bit of $s$. We need exactly $n$ queries to determine all $n$ bits. The classical query complexity is $\Theta(n)$.

We cannot do better deterministically: if we make fewer than $n$ queries, the remaining bits of $s$ are unconstrained — we have zero information about them.

The Quantum Circuit — Same as DJ!

Remarkably, the BV algorithm uses the exact same circuit as Deutsch-Jozsa. The difference is only in the oracle and the interpretation of the output.

Bernstein-Vazirani Circuit: |0⟩^n ─── H^n ─── U_f ─── H^n ─── [M^n] ─── gives s directly! |1⟩ ─── H ─────────────────── (not measured)

Full Derivation

Steps 1–3 are identical to DJ. After phase kickback:

$$|\psi_2\rangle = \frac{1}{\sqrt{2^n}}\sum_x (-1)^{f_s(x)}|x\rangle|{-}\rangle = \frac{1}{\sqrt{2^n}}\sum_x (-1)^{s\cdot x}|x\rangle|{-}\rangle$$

Now apply $H^{\otimes n}$ to the query register. Using the fact that $H^{\otimes n}|s\rangle = \frac{1}{\sqrt{2^n}}\sum_x (-1)^{s\cdot x}|x\rangle$ (the Hadamard transform of a computational basis state $|s\rangle$ is exactly the superposition we have!), we get by the inverse Hadamard transform:

$$|\psi_3\rangle = |s\rangle|{-}\rangle$$

We measure the query register and get $s$ with certainty. Just 1 query, regardless of $n$. The quantum speedup is from $n$ queries to 1 query.

🔍 The Deep Reason

The BV algorithm works because the function $f_s(x) = s\cdot x$ is linear over GF(2), and the Hadamard transform is the quantum Fourier transform over GF(2). The algorithm essentially performs a Fourier analysis of the function in one shot, using quantum superposition to probe all frequencies simultaneously. This insight directly generalizes: Shor's algorithm uses the Quantum Fourier Transform over $\mathbb{Z}_N$.

Complexity Separation: BPP vs BQP

The BV problem gives an oracle separation between BPP and BQP — the first such separation. In the oracle query model:

$$Q(BV_n) = 1 \quad \text{vs} \quad R(BV_n) = n \quad \text{(randomized classical)}$$

No randomized classical algorithm can solve BV in fewer than $n$ queries: each query gives only 1 bit of information about $s$, and $s$ has $n$ bits. The quantum algorithm extracts all $n$ bits in a single "parallel" query, exploiting superposition.

Grover's Quantum Search Algorithm

Grover's algorithm is arguably the most broadly applicable quantum algorithm known. While DJ and BV solve rather specific problems, Grover's algorithm solves the general unstructured search problem that arises in almost every domain of computing.

📐 The Unstructured Search Problem

Given a function $f: \{0,1\}^n \to \{0,1\}$ (with $N = 2^n$ inputs), find an input $x^*$ such that $f(x^*) = 1$. Such $x^*$ is called a marked element. Assume there is exactly one marked element (generalization to $k$ solutions is straightforward).

Classically: No better strategy than random search. Expected $O(N)$ queries; worst case $N$ queries.

Quantum (Grover): $O(\sqrt{N})$ queries. Provably optimal for quantum algorithms.

This is a quadratic speedup: from $O(N) = O(2^n)$ to $O(\sqrt{N}) = O(2^{n/2})$. For a billion-element database ($N = 10^9$), classical search needs $\sim 500$ million queries on average, while Grover needs $\sim 31,623$ queries. The speedup is real and useful for NP-complete problems (though it doesn't give polynomial speedup for NP).

The Phase Oracle for Grover

Grover's algorithm uses the phase oracle $O_f$ that applies a phase of $-1$ to the marked element and leaves all others unchanged:

$$O_f|x\rangle = \begin{cases} -|x\rangle & \text{if } f(x) = 1 \text{ (marked)} \\ +|x\rangle & \text{otherwise} \end{cases} = (-1)^{f(x)}|x\rangle$$

As shown earlier (phase kickback trick), this can be implemented using the standard oracle $U_f$ with the ancilla prepared in $|{-}\rangle$. The oracle "marks" the target by flipping its phase.

Geometric Framework: The Key Intuition

The most illuminating way to understand Grover's algorithm is geometrically. Define two important states:

$$|a\rangle = |x^*\rangle \quad \text{(the marked/answer element)}$$ $$|e\rangle = \frac{1}{\sqrt{N-1}}\sum_{x \neq x^*} |x\rangle \quad \text{(uniform superposition over non-marked elements)}$$

The initial uniform superposition state $|U\rangle = \frac{1}{\sqrt{N}}\sum_x |x\rangle$ can be written in terms of these:

$$|U\rangle = \sqrt{\frac{N-1}{N}}|e\rangle + \frac{1}{\sqrt{N}}|a\rangle = \cos\!\left(\frac{\theta}{2}\right)|e\rangle + \sin\!\left(\frac{\theta}{2}\right)|a\rangle$$ where $\sin(\theta/2) = 1/\sqrt{N}$, so $\theta/2 \approx 1/\sqrt{N}$ for large $N$, giving $\theta \approx 2/\sqrt{N}$.

The state lives in the 2D subspace $\text{span}\{|a\rangle, |e\rangle\}$. Each Grover iteration is a rotation by angle $\theta$ in this 2D plane, rotating the state vector toward $|a\rangle$!

🎯 Geometric Picture of Grover Iteration

Each Grover iteration consists of two reflections (which compose to give a rotation by $\theta$):

  1. Phase oracle $O_f$: Reflects the state about the $|e\rangle$ axis (flips the $|a\rangle$ component's sign). Geometrically: reflection about the hyperplane perpendicular to $|a\rangle$.
  2. Diffusion operator $D$: Reflects the state about the initial superposition $|U\rangle$. Geometrically: reflection about $|U\rangle$.

Two reflections = one rotation! The angle of rotation is $\theta$ (twice the angle between $|e\rangle$ and $|U\rangle$).

The Diffusion Operator

The diffusion operator $D$ (also called the Grover diffusion operator or inversion-about-average) is:

$$D = 2|U\rangle\langle U| - I = H^{\otimes n}(2|0\rangle\langle 0| - I)H^{\otimes n}$$

Its matrix action on a state with amplitudes $\alpha_x$ is:

$$D|\psi\rangle: \quad \alpha_x \mapsto 2\langle\alpha\rangle - \alpha_x$$

where $\langle\alpha\rangle = \frac{1}{N}\sum_x \alpha_x$ is the mean amplitude. This is the "inversion about the mean" operation: amplitudes below the mean are increased, amplitudes above the mean are decreased. After the oracle makes the marked element's amplitude negative, the diffusion operator "reflects" it to be much larger than average — amplification!

✏️ Step-by-step Amplitude Example (N=4)

Let $N=4$, $|a\rangle = |11\rangle$. Initial state: $|\psi_0\rangle = \frac{1}{2}(|00\rangle + |01\rangle + |10\rangle + |11\rangle)$. All amplitudes = $+\frac{1}{2}$. Mean = $\frac{1}{2}$.

After oracle: Amplitude of $|11\rangle$ flips to $-\frac{1}{2}$. Others stay $+\frac{1}{2}$. New mean = $\frac{1}{4}(3\cdot\frac{1}{2} + (-\frac{1}{2})) = \frac{1}{4}$.

After diffusion (inversion about mean $\frac{1}{4}$):

  • $|00\rangle, |01\rangle, |10\rangle$: $2\cdot\frac{1}{4} - \frac{1}{2} = 0$!
  • $|11\rangle$: $2\cdot\frac{1}{4} - (-\frac{1}{2}) = 1$!

After just ONE iteration, $|11\rangle$ has amplitude $1$ — the algorithm succeeds with probability 100% for $N=4$!

Full Algorithm and Number of Iterations

$$\text{Grover's Algorithm:}$$
  1. Prepare $|U\rangle = H^{\otimes n}|0\rangle^{\otimes n}$ (uniform superposition)
  2. Repeat $T$ times: apply $G = D \cdot O_f$ (one Grover iterate)
  3. Measure; return result

After $T$ iterations, the state is:

$$|\psi_T\rangle = \cos\!\left(\frac{(2T+1)\theta}{2}\right)|e\rangle + \sin\!\left(\frac{(2T+1)\theta}{2}\right)|a\rangle$$

Probability of measuring the correct answer: $P(x^*) = \sin^2\!\left(\frac{(2T+1)\theta}{2}\right)$

This is maximized when $\frac{(2T+1)\theta}{2} = \frac{\pi}{2}$, i.e., $T = \left\lfloor\frac{\pi}{2\theta} - \frac{1}{2}\right\rfloor \approx \frac{\pi}{4}\sqrt{N}$

Optimality: The BBBV Lower Bound

The $O(\sqrt{N})$ query complexity of Grover's algorithm is provably optimal — no quantum algorithm (no matter how clever) can search an unordered database faster. This was proven by Bennett, Bernstein, Brassard, and Vazirani (1996) using the "polynomial method".

⚠️ Implications for NP

Grover's algorithm cannot solve NP-complete problems in polynomial time. For an NP problem with $N = 2^n$ solutions to check: classical brute force takes $O(2^n)$ queries; Grover takes $O(2^{n/2})$ — still exponential! The speedup is "only" quadratic, not polynomial. So Grover does not imply $BQP \supseteq NP$.

Success Probability and Repetition

If we run exactly $T = \lfloor\frac{\pi}{4}\sqrt{N}\rfloor$ iterations, the success probability $P(x^*) = \sin^2(\frac{(2T+1)\theta}{2})$ is at least $1 - \frac{1}{N}$, which approaches 1 for large $N$. For small $N$, we might need to optimize $T$ more carefully (exact values for small $N$: $N=4$ needs $T=1$, $N=8$ needs $T=2$, etc.).

If we're uncertain or if there might be zero solutions, we can repeat the algorithm $O(\log(1/\delta))$ times to reduce failure probability to $\delta$.

✏️ Grover Pseudocode
Algorithm GROVER(oracle O_f, n qubits, N = 2^n):
  T_opt ← ⌊(π/4)·√N⌋    // optimal number of iterations
  |ψ⟩ ← H^⊗n |0⟩^n      // uniform superposition

  for t = 1 to T_opt:
    |ψ⟩ ← O_f |ψ⟩         // Phase oracle: flip phase of |x*⟩
    |ψ⟩ ← D |ψ⟩            // Diffusion: invert about mean
    // D = H^n · (2|0⟩⟨0| - I) · H^n

  result ← MEASURE(|ψ⟩)   // Succeeds with prob ≥ 1 - 1/N
  return result
